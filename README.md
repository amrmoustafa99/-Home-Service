# Home Services

Shared Flutter project foundation for the Home Services application.

This repository currently contains the app structure only. Authentication, profile, Firebase, and feature UI are not implemented yet.

## Branches

- `main` — stable production/integration branch
- `feature/team-a-auth` — Team A (onboarding, auth, Firebase Authentication)
- `feature/team-b-profile` — Team B (profile, Firestore, Firebase Storage)

## Getting started

```sh
flutter pub get
flutter analyze
flutter run
```
